# Hotel Management System

## Project Overview
A Java-based console application that manages hotel rooms and guest bookings. It demonstrates Object-Oriented Programming, Java Collections, and Exception Handling.

## Features
- View all hotel rooms
- View available rooms
- Book a room
- Search booking details using Booking ID
- Check in guests
- Check out guests and generate bills
- Manage room availability after checkout

## Technologies Used
- Java
- Java Collections (`ArrayList`, `HashMap`, `Map`)
- Exception Handling
- Scanner for user input
- Eclipse IDE

## How to Run
1. Install the Java Development Kit (JDK).
2. Clone or download this repository.
3. Open the project in Eclipse.
4. Run `HotelManagementSystem.java` as a Java application.
